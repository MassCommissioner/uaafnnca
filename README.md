# Junteng Liu — Personal Academic Homepage

Personal academic homepage of **Junteng Liu**, built with the
[Academic Pages](https://github.com/academicpages/academicpages.github.io) Jekyll template and
filled in with the personal details, academic background, research experience, publications and
contact information stored in memory.

## Structure

- `_config.yml` — site-wide configuration (name, e-mail, GitHub, Google Scholar, X/Twitter)
- `_pages/about.md` — homepage: bio, research interests, education, research experience,
  publications, awards and contact information
- `_pages/publications.html` — publications subpage
- `_publications/` — one Markdown file per publication
- `_data/navigation.yml` — header navigation (Publications only; no other pages are used)
- `_layouts/`, `_includes/` — a small, self-contained rendering theme so the site builds
  without the upstream theme assets (which include binary images that cannot be pushed
  through the repository API)
